# User Guide

Run the application and choose an option by typing its number.

## Menu Options

- `1` shows products in pages of 20 rows.
- `2` adds a product.
- `3` sorts products by price.
- `4` sorts products by quantity.
- `5` searches by product name.
- `6` shows the total inventory value.
- `7` updates a product quantity by row number.
- `8` deletes a product by row number.
- `9` saves the current inventory.
- `10` reloads products from the CSV file.
- `0` saves and exits.

The default data file is `resources/products.csv`.
